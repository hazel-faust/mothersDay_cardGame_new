# 母親節翻牌小遊戲

這是一個手機也可以玩的母親節翻牌網頁遊戲。

## 使用方式

1. 解壓縮整個資料夾。
2. 打開 `index.html`。
3. 點第一張牌後，25 秒倒數才會開始。

## 遊戲規則

- 場上共有 16 張牌。
- 其中 14 張是 7 組媽媽照片配對卡。
- 另外 2 張是烏龜 bonus 卡：
  - `bonus_time.jpg`：加 5 秒。
  - `bonus_score.jpg`：加 300 分。
- 越快配對成功，分數越高。
- 通關後，如果分數進入前五名，可以輸入暱稱留下排行榜紀錄。
- 排行榜存在同一台手機/瀏覽器中。

## 圖片資料夾

程式會優先讀取 `image/` 資料夾，也支援 `images/`。請讓圖片資料夾和 `index.html` 放在同一層。

如果按「重新開始」或「再試一次」後圖片空白，通常是圖片資料夾沒有和 `index.html` 放在一起，或資料夾名稱被改掉。
